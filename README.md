# Potend Pound (Paper 26.2, Java 25)

Build:  gradle build        (Gradle 9.1+ / JDK 25)  ->  build/libs/PotendPound-1.0.0.jar
Install: drop the jar in plugins/, restart, then /potendpound give [player]
Resource pack: PotendPound-ResourcePack.zip  (host it and set resource-pack.url + sha1 in config.yml,
               or load it any other way). Pack format 88 (26.2).
